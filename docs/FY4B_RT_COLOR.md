# FY4B RTEC 日间配色

按用户最终要求，以原有配色系数为基础微调，撤销新的 SRF 瑞利参数、NIR 权重变化、亮云中性化和全亮度去黄。

保留原有瑞利参数 0.1726 / 0.0501 / 0.0187、红色混合矩阵 -0.1992 / 1.3768 / -0.1770、合成绿色权重 0.45 / 0.45 / 0.10、绿色 0.85 次幂、蓝色 0.75 次幂及 1.06 增益。
仅将 FY4B 红色从 0.85 次幂、0.90873 增益微调为 0.87 次幂、0.90 增益，轻微减少暖色。
显示峰值超过 0.82 时使用连续指数高光压缩，再同比例缩放 RGB，避免纯白截断；不抬高暗部。
FY4A 原有色调及夜间 EC 合成保持原样。

Surigae 使用目录内 2026-09-27 数据。区域中心 24.9°N、128.5°E 来自图像位置估计，范围为 10° × 10°。
FY4B 原图与区域图使用 1KM 可见光和 4KM 红外辅助数据。
